What I Built:

งานนี้ผมได้สร้างเว็บไซต์ My First Learning Portfolio มีส่วนประกอบสำคัญคือโค้ด HTML และ CSS กับส่วน body ที่เขียนขึ้น ในขณะที่เปิดเว็บไซต์นี้จากคอมของผมเอง

มี client เกิดขึ้นแล้วแต่ server ยังไม่เกิดขึ้น เพราะ client คือ web browser ในคอมผมเอง ส่วน server ยังไม่เกิดเพราะเป็นการเปิดไฟล์ในเครื่องตัวเอง

How I Built It:

ขั้นตอนในการพัฒนางานนี้:

  1. ใช้ Gemini notebook สรุปว่าต้องทำอะไรบ้าง
  2. เขียนข้อความในส่วน body
  3. เขียน HTML แล้วนำข้อความที่เขียนไว้มาใส่
  4. ตกแต่งด้วย CSS
  5. ลองเปิดเว็บไซต์ว่าสมบูรณ์หรือไม่

Reflection:

  • ปัญหาหรือความท้าทายที่พบ: คือ การต้องใช้ Semantic HTML แทน <div> หรือ <p> ที่ใช้เป็นประจำ วิธีรับมือคือ ฝึกใช้ไปเรื่อยๆ จนชินไปเอง
  • สิ่งที่เข้าใจมากขึ้นเกี่ยวกับการพัฒนาเว็บไซต์: คือ การใช้ Semantic HTML และ การตกแต่งด้วย CSS
  • หากได้พัฒนาต่อ: อยากปรับปรุงการตกแต่งด้วย CSS เพราะยังไม่ชำนาญ และอยากศึกษาเพิ่มเติมเพื่อจัดวางเลย์เอาต์ให้หน้าเว็บมีความสวยงาม เป็นระเบียบ และน่าอ่านมากยิ่งขึ้น
